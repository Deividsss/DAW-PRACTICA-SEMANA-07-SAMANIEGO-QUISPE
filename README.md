# Celebrity Explorer DEISAM – Guía Práctica Semana 07 (React Hooks)

Explora un catálogo local de figuras históricas, busca por nombre o disciplina,
consulta sus aportes y guarda tus favoritas.

```bash
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build
```

Hooks usados: useState, useEffect, useContext, useReducer, useMemo, useCallback,
useRef, memo y hooks personalizados (useKeyPress).
